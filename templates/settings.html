Settings

API credentials for the services this app talks to. Saving a field here overrides `.env` immediately -- no restart needed. Secret values are never shown back once saved; the field just tells you whether one is set. "Reset" drops the override and falls back to whatever `.env` has (or blank, if `.env` doesn't set it either). To change your dashboard login username or password instead, see Account.

Clip-selection autonomy

How much freedom the pipeline has to pick clips into a compilation on its own. "Manual" (default) means you always assemble one yourself from Build. "Assisted" tells you (in the server logs) once enough top-ranked material exists for a 60-90s compilation, but still waits for you to build it. "Autonomous" builds one automatically (straight cuts, never uploads) once enough exists. You can always trigger the same builder by hand from the Compilations page regardless of this setting.
