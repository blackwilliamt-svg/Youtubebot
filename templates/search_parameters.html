Search parameters

One unified list of search terms shared by all three platforms -- Reddit keyword search (sorted "hot"), TikTok hashtag search, and Instagram hashtag search. Adding one here doesn't verify it returns anything -- a bad term just yields nothing from that search, nothing breaks. Removing one only stops future pulls; clips already collected from it are untouched. This list also grows and shrinks itself: a tag crossing 3 liked (or disliked) clips in Triage gets added (or removed) automatically -- see the Stats page for triage approval rates.
