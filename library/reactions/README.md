# library/reactions/<category>/

Drop short reaction video clips (`.mp4` / `.mov` / `.webm` / `.gif`) into
the matching category subfolder:

    library/reactions/fails/
    library/reactions/animals/
    library/reactions/gaming/
    library/reactions/wins/
    library/reactions/oddly-satisfying/
    library/reactions/mildly-infuriating/

They show up as selectable items on the /build sequencing screen,
alongside your scraped clips -- fully manual insertion, nowhere in the
pipeline are they ever auto-selected or auto-placed. Place one wherever
you want in the sequence using the same ▲▼ controls as any other item;
they count toward the 58s cap and the 10-item soft-warning threshold
exactly like a scraped clip.
